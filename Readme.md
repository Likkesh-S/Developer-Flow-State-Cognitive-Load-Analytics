# CogniStream: Developer Flow-State & Cognitive Load Analytics

## Project Overview

CogniStream is a data analytics and machine learning project designed to analyze developer activity patterns, focus sessions, interruptions, context switching, and potential cognitive workload indicators.

The project uses Python, SQL, machine learning, and Power BI to transform activity data into meaningful insights about developer work patterns.

## Problem Statement

Developers often experience interruptions, frequent task switching, and changing workloads during software development. These patterns can affect concentration and work efficiency.

CogniStream analyzes developer activity data to identify focus patterns, understand interruptions, and visualize workload trends.

## Objectives

- Analyze developer activity data.
- Measure focus-session duration.
- Identify interruptions and context switching.
- Explore potential cognitive-load indicators.
- Apply machine learning to classify activity patterns.
- Build an interactive Power BI dashboard.
- Generate insights to support healthier work practices.

## Important Note

Cognitive-load indicators are exploratory estimates derived from activity patterns. They are not medical measurements or definitive assessments of an individual's mental state.
