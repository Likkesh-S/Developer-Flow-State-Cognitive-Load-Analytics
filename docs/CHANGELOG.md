## Changelog Maintenance Guidelines

Whenever the project is updated:

1. Add a new version or update entry.
2. Record the date of the change.
3. List new features under Added.
4. List modifications under Changed.
5. List bug fixes under Fixed.
6. List removed functionality under Removed.
7. Update the version number when appropriate.

## Version Format

The project follows a simple versioning format:

- MAJOR: Significant changes that may break compatibility.
- MINOR: New features that remain compatible.
- PATCH: Bug fixes and small improvements.

Example:

- 1.0.0 - Initial project release.
- 1.1.0 - Added new dashboard features.
- 1.1.1 - Fixed a minor issue.
