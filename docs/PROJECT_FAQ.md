# CogniStream – Project Viva Questions and Answers

## Section 1: Basic Project Questions

### Q1. What is the title of your project?

**Answer:**

My project title is "CogniStream: Developer Flow-State & Cognitive Load Analytics".

### Q2. What is CogniStream?

**Answer:**

CogniStream is a data analytics project that explores developer activity patterns using Python, SQL, machine learning, and data visualization.

### Q3. What is the main objective of this project?

**Answer:**

The main objective is to analyze simulated developer activity data, including coding time, interruptions, context switching, focus indicators, and workload indicators.

### Q4. Why did you choose this project?

**Answer:**

I chose this project because it combines data analytics, Python programming, SQL, machine learning, and dashboard development in one practical application.

### Q5. What problem does this project address?

**Answer:**

It addresses the challenge of organizing and analyzing developer activity information to understand activity patterns and trends.

## Section 2: Dataset Questions

### Q6. Which dataset is used?

**Answer:**

The project uses a simulated dataset named `developer_activity.csv`.

### Q7. What are the main columns in the dataset?

**Answer:**

The main columns are timestamp, developer_id, coding_minutes, interruption_count, context_switches, task_complexity, break_minutes, focus_score, and cognitive_load_score.

### Q8. What is data cleaning?

**Answer:**

Data cleaning is the process of identifying and correcting data-quality problems such as missing values, duplicate records, and invalid values.

### Q9. Why is data cleaning important?

**Answer:**

It improves data quality and helps prepare reliable input for analysis.

### Q10. What is feature engineering?

**Answer:**

Feature engineering is the process of creating useful new variables from existing dataset columns.

## Section 8: Limitations and Future Scope

### Q36. Is your dataset real or simulated?

**Answer:**

The current dataset is simulated and is used for educational and analytical demonstration.

### Q37. Can this project measure a person's actual cognitive load?

**Answer:**

No. The current project uses illustrative numerical indicators. It cannot measure or diagnose a person's actual cognitive state.

### Q38. What are the limitations of your project?

**Answer:**

The dataset is small and simulated. The model requires further validation, and the results cannot be generalized to real developers.

### Q39. What are the future enhancements?

**Answer:**

Future enhancements include larger representative datasets, improved model validation, more dashboard features, and privacy-conscious real-time analytics.
